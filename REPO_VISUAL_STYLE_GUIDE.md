# Repo Visual Style Guide

## Hallmark Direction
Luxury planner notebook + intelligent bridal concierge.

## What The User Should Feel
- This is calm.
- This is serious.
- This understands constraints.
- This will help me talk to vendors and planners.
- This will not pretend to know live availability or exact prices.

## Homepage Macrostructure
Use a hybrid of:
- Letter / Editorial Manifesto
- Photographic / Planner Table
- Narrative Workflow

Homepage must include:
- a strong editorial opening
- one primary CTA
- one secondary CTA
- a planner-packet preview
- visible trust markers
- fewer generic grids
- editorial feature bands

## Build Page Macrostructure
Use a Workbench / Narrative Workflow hybrid.

The build page must preserve numbered steps:
- Step 0: Reality Check
- Step 1: Planner Brain
- Step 2: Venue Strategy
- Step 3: Budget Reality
- Step 4: Design Language
- Step 5: Vendor Questions
- Step 6: Standout Ideas
- Step 7: Planner Packet

The build page should feel like a guided planner desk, not an admin dashboard.

## Empty State Language
Use calm planning language:
- Not decided yet
- Add when ready
- We will carry this assumption into your packet
- Needs verification before booking

Avoid:
- Unknown, when it feels like a deficiency
- Error-like empty states
- shamey or completion-pressure language

## Trust Language
Trust language should be designed into the product, not buried in fine print.

Required markers:
- Seeded examples only
- No live availability claimed
- Verify before booking
- Confidence labels included
- Planner packet records assumptions

## Anti-Slop Guardrails
Flag these as visual risks:
- repeated rounded cards without rhythm
- repeated pills as primary structure
- generic AI/SaaS dashboard density
- card grids replacing editorial sequencing
- no premium visual anchor
- CTA competition
