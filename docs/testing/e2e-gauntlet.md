# E2E Gauntlet

The Playwright gauntlet must prove four layers:

1. Surface: routes render and critical UI appears.
2. Transaction: user actions update state.
3. Outcome: the app promise is fulfilled.
4. Common sense: the app avoids unsafe, fake, or hostile outcomes.

Required proof includes no-auth access, build flow, budget modes, strict-budget escape hatch, trend add-to-dashboard, trend submission review intake, photo consent before analysis, purchase-vs-execution cost distinction, Starter Pack disclaimers, mobile usability, and print route readiness.
