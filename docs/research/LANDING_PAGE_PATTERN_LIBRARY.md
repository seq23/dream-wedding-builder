# Landing Page Pattern Library

Required order for each paid hero page:
1. Product-specific outcome and price.
2. Exact deliverables.
3. Best-fit buyer.
4. Working outcome and prevented failure.
5. Five-step use process.
6. Free/generic alternative comparison.
7. Product-specific objections.
8. Delivery, support, license, and safety boundaries.
9. Suite upsell.
10. Final purchase CTA.

Forbidden patterns:
- Identical pages with only product names swapped.
- Hidden prices.
- Fake reviews or usage numbers.
- Vague "AI-powered" claims.
- Checkout before explaining delivery.
- Public links to paid assets.
